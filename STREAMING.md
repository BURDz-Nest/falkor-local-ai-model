# 🌊 Streaming Responses - Typewriter Effect

## What We Added

Falkor now streams responses token-by-token as they're generated by Ollama, creating a smooth typewriter effect just like ChatGPT!

---

## ✨ Features

### Before (No Streaming):
```
You: What is Python?

Falkor: [3 second delay...]

Python is a high-level programming language created by Guido van Rossum...
[entire response appears at once]
```

### After (With Streaming):
```
You: What is Python?

Falkor: P█
        Py█
        Pyt█
        Pyth█
        Pytho█
        Python█
        Python is█
        ...
[text appears smoothly as it's generated]
```

## 🔧 How It Works

### 1. OllamaClient.chat_stream()

**New method** that yields tokens as they arrive:

```python
def chat_stream(
    self,
    model: str,
    messages: List[Dict[str, str]]
) -> Iterator[str]:
    """Stream response chunks from Ollama."""
    # Ollama streams NDJSON (newline-delimited JSON)
    for line in response.iter_lines():
        data = json.loads(line)
        yield data["message"]["content"]
```

**Key features:**
- Uses httpx streaming
- Parses NDJSON format
- Yields content chunks immediately
- No buffering delay

---

### 2. FalkorRenderer.render_streaming_response()

**New method** that displays tokens as they arrive:

```python
def render_streaming_response(self, stream_iterator):
    """Render with typewriter effect."""
    full_response = []
    
    for chunk in stream_iterator:
        if chunk:
            full_response.append(chunk)
            # Print immediately - no buffering!
            self.console.print(chunk, end="", markup=False)
    
    return "".join(full_response)
```

**Key features:**
- Prints chunks immediately (typewriter effect!)
- Accumulates full response for history
- No markup parsing (raw text)
- Smooth, no flickering

---

### 3. Updated FalkorApp.run()

**Changed from:**
```python
# Old: Wait for complete response
response = self.client.chat(
    model=self.model,
    messages=self.conversation_history
)
assistant_message = response["message"]["content"]
self.renderer.render_markdown(assistant_message)
```

**To:**
```python
# New: Stream response token-by-token
stream = self.client.chat_stream(
    model=self.model,
    messages=self.conversation_history
)
assistant_message = self.renderer.render_streaming_response(stream)
```

## 📊 Technical Details

### Ollama Streaming Format

Ollama streams **NDJSON** (Newline-Delimited JSON):

```json
{"model":"llama3.1:8b","message":{"role":"assistant","content":"Hello"}}
{"model":"llama3.1:8b","message":{"role":"assistant","content":" there"}}
{"model":"llama3.1:8b","message":{"role":"assistant","content":"!"}}
{"done":true}
```

Each line is a complete JSON object with:
- `model`: Model name
- `message.content`: Text chunk (token or group of tokens)
- `done`: True on final line

### HTTPX Streaming

```python
with self.client.stream("POST", url, json=payload) as response:
    for line in response.iter_lines():
        # Process each line as it arrives
        data = json.loads(line)
        yield data["message"]["content"]
```

**Benefits:**
- Connection stays open
- Chunks arrive in real-time
- Low latency
- No buffering

### Rich Console Output

```python
self.console.print(chunk, end="", markup=False)
```

**Parameters:**
- `end=""`: No newline (continuous text)
- `markup=False`: Raw text (no Rich formatting)
- Immediate flush to terminal

## 🛠️ Troubleshooting

### Problem: No streaming, response appears all at once

**Cause**: Terminal buffering

**Solution**:
```bash
# Run with unbuffered output
python -u main.py
```

### Problem: Streaming is choppy

**Cause**: Slow model or CPU

**Solution**: Use a smaller/faster model:
```bash
~/bin/ollama pull qwen2.5:1.5b
```

### Problem: Connection timeout

**Cause**: Long response + default timeout

**Solution**: Already fixed! We use:
```python
httpx.Timeout(60.0, read=300.0)  # 5min read timeout
```
