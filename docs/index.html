🐉 Falkor

Beautiful local AI assistant powered by Ollama

Features

  • ChatGPT-like streaming responses - Smooth typewriter effect
  • 100% local - Complete privacy, works offline
  • Interactive model selector - Switch models with arrow keys
  • Built-in Help Agent - Auto-helps with Falkor/Ollama questions
  • Cross-platform - macOS, Linux, Windows
  • Easy installation - One command to get started

Installation

🍎 macOS / Linux

curl -fsSL https://raw.githubusercontent.com/BURDz-Nest/falkor-local-ai-model/main/install.sh | bash

🪟 Windows (PowerShell)

irm https://raw.githubusercontent.com/BURDz-Nest/falkor-local-ai-model/main/install.ps1 | iex

What it does:

  • Checks for Python 3.11+
  • Installs/checks Ollama
  • Downloads default model (gemma2:2b ~1.6GB)
  • Creates falkor command
  • Takes 5-10 minutes depending on connection

Getting Started

After installation, just type:

falkor

You'll see:

🐉 Welcome to Falkor!
Model: gemma2:2b

You:

Start chatting! Try:

  • "What is Python?"
  • "Explain recursion"
  • "Write a function to reverse a string"
  • "how do i get more models?" (triggers Help Agent!)

Default Model gemma2:2b

Falkor starts with gemma2:2b - the perfect balance of speed and quality.

Why gemma2:2b?

  • Fast - Quick responses (~50-80 tokens/sec)
  • Smart - Better quality than 1.5b models
  • Small download - Only 1.6GB
  • Low RAM - Works with 4GB RAM
  • Great Help Agent - Follows instructions well

Getting More Models

1. Browse Available Models

Visit ollama.com/library or check what's installed:

ollama list

2. Pull Any Model

ollama pull <model-name>

Examples:

# Great all-around (4.7GB, 8GB RAM)
ollama pull llama3.1:8b

# Best for coding (19GB, 20GB RAM)
ollama pull qwen2.5-coder:32b

# Fast and tiny (700MB, 2GB RAM)
ollama pull qwen2.5:1.5b

# Excellent for instructions (4.1GB, 8GB RAM)
ollama pull mistral:7b

3. Verify It Worked

ollama list

Your new model should appear!

4. Use in Falkor

  1. Restart Falkor: exit then falkor
  2. Type: /model
  3. Use ↑↓ arrow keys to select
  4. Press Enter

⚠️ Hardware Considerations

  • Small models (1-3b) - ~2-4GB RAM
  • Medium models (7-8b) - ~8GB RAM minimum
  • Large models (30b+) - ~20-32GB RAM required
  • Rule of thumb: Model size in GB ≈ RAM needed
  • If struggling: Use a smaller model!

You: how do i get more models?

1. Pull any model:
   ollama pull <model-name>

  • Falkor features
  • Troubleshooting
  • Performance issues

/help-agent <your question>

Examples:

/help-agent what models should I use for coding?
/help-agent why is it slow?

Custom Models (Advanced)

You can use models from HuggingFace or create custom configurations!

Import GGUF from HuggingFace

  1. Download a GGUF file from HuggingFace
  2. Create a Modelfile: 
    FROM ./path/to/model.gguf
  3. Create in Ollama: 
    ollama create my-custom-model -f Modelfile
  4. Verify: ollama list
  5. Use in Falkor: Restart and /model

For more details, ask the Help Agent: /help-agent how do I use custom models?

Commands Reference

Tips & Best Practices

💡 Getting the Best Experience

  • Start with gemma2:2b - Great default, upgrade later if needed
  • Match model to hardware - Model size ≈ RAM needed
  • Use Help Agent - Just ask "how do i..." questions
  • Try different models - Each excels at different tasks
  • Browse ollama.com/library - Discover new models

🚀 Performance Tips

  • If responses are slow: Use a smaller model (qwen2.5:1.5b)
  • If system freezes: Model is too big for your RAM
  • Close other apps: Free up RAM for better performance
  • SSD vs HDD: Models load faster from SSD

📚 Model Recommendations

  • Daily use: gemma2:2b or llama3.1:8b
  • Coding: qwen2.5-coder:7b or qwen2.5-coder:32b
  • Conversations: llama3.1:8b or qwen2.5:7b
  • Instructions: mistral:7b
  • Low RAM: qwen2.5:1.5b
